## New blocker

**N2: on Kubernetes, the Postgres password does not come from `aegis-db-credentials`.**

- Postgres uses a hardcoded `aegis-secret-pw`.
- The control plane and the gateway's audit sidecar use the operator's `AEGIS_DB_PASSWORD`. They only work if the operator happens to pick that same string.
- Compose is not affected.
- The fix is to read the Postgres user and password through `secretKeyRef`, plus a manifest test that both sides use the same Secret.

## Integration (re-audit 4 checker)

- **Wired:** N1, the two-phase drain, Connection: close, HAProxy tracking, every recorder, the latency histogram, the body limit on both listeners, the 101 refusal, and the simulator's snapshot_version fill.
- **Not a bypass:** `statusRecorder.Unwrap` lets ReverseProxy hijack connections for upgrades. That makes the 101 refusal load-bearing, and `upgrade_test.go` locks it in. No shipped route uses websockets or SSE.
