| stream message fields -> ack tracker | GatewayId in messages is attacker-controlled; the cert is the only identity source |

| T-11-04-02 | Spoofing | Plaintext or wrong-CA client | mitigate | RequireAndVerifyClientCert with Aegis root CA; handler-level Unauthenticated if no TLSInfo; tests assert rejection |
