  <behavior>
    - Reconstruct loads unexpired quarantines and revocations from the repo, computes remaining = ExpiresAt - now (skips <=0, floors at 1s), restores them with remaining TTL (never the 24h default), and ONLY THEN sets the marker. If restoring errors the marker is not written and the error is returned.
    - Backfill: when the marker is absent AND Redis already contains quarantine:principal:* / revocation:jti:* keys (pre-Phase-11 data), those are imported into the repo (ExpiresAt = now + TTL, CreatedBy "backfill") before the first reconstruct, so they are neither lost nor pruned; when Redis is empty (post-FLUSHALL) backfill is a no-op.
    - Run: every marker-check interval (default 2s) checks the marker and calls Reconstruct when missing (miniredis FlushAll -> marker back within one interval and quarantines restored); every reconcile interval (default 30s) calls DeleteExpired and re-asserts all unexpired repo rows into Redis (partial restore with an old marker heals); Redis keys that have no repo row are removed ONLY after a successful backfill has completed once in this process.
    - Metrics: SecurityStateReconstructTotal{result=ok|error} increments and last-reconstruct timestamp set on success.
    - Ready(ctx) returns an error when the pinger fails or the marker is missing, nil otherwise.
    - Concurrent calls to Reconstruct from two goroutines are race-free and idempotent.
  </behavior>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator HTTP -> control plane | Authenticated operator actions mutate security state |
| control plane -> Postgres / Redis | Dual write; Postgres is authoritative |
| unauthenticated probes | /livez /readyz reachable without a session |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-05-01 | Elevation of Privilege | Quarantine/revocation lost on Redis wipe | mitigate | PG-first write-through + reconstruct + reconcile; tests with FlushAll |
| T-11-05-02 | Tampering | Partial failure leaves PG and Redis divergent | mitigate | 503 on either failure, PG row kept, idempotent retries, 30s reconcile heals |
| T-11-05-03 | Elevation of Privilege | Resurrection race (reconstruct vs unquarantine) | mitigate | Reconcile full-sync prune after backfill; window <= reconcile interval, documented |
| T-11-05-04 | Information Disclosure | /readyz leaking internals | mitigate | Body limited to a two-value enum, no error strings |
| T-11-05-05 | Denial of Service | Reconstruct storm | mitigate | Mutex serialises Reconstruct; idempotent across HA replicas; bounded intervals |
| T-11-05-06 | Repudiation | Who quarantined | mitigate | created_by from session actor persisted in PG |
| T-11-05-07 | Tampering | Legacy Redis keys pruned before import | mitigate | Prune only after successful backfill in-process |
| T-11-05-SC | Tampering | package installs | accept | No new packages |
