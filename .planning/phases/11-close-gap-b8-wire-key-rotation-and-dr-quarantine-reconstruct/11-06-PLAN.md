    - LoadDir: reads dir with os.ReadDir, skips entries whose name starts with ".", reads remaining regular files with os.ReadFile (following symlinks, so K8s `..data` layouts with per-key symlinks work), parses with keyfile.ParseEd25519Public, sorts by file name, dedupes identical keys; returns an error if the dir is unreadable, zero keys result, or ANY file fails to parse (no partial sets).
    - Names like `keyset.pub.0`, `keyset.pub.1`, `current.pub`, `new.pub` are all accepted; `.hidden`, `..data` (a directory) and `..2024_01_01` are ignored. A subdirectory entry that is not dot-prefixed is ignored (not an error).
    - Load applies the set once; Reload computes a sha256 over the sorted raw keys and skips apply (result "unchanged") when identical; apply is invoked once per distinct change.
    - A bad reload (empty dir, garbage file added, dir removed) leaves the previously applied set untouched, returns an error, logs, and increments KeysetReloadTotal{family,result="error"}; a following good reload recovers (result "ok"); KeysetKeys gauge and last-success timestamp update on ok.
    - Run: reloads on every interval tick and immediately on SIGHUP; exits on ctx.Done(); the SIGHUP handler is stopped (signal.Stop) on exit.
    - Concurrency: with a real snapshot.Verifier and identity.TokenValidator as apply targets, hundreds of concurrent verifications during repeated swaps are race-free (`-race`) and never observe an empty key set.
    - ParseInterval returns the default for empty/invalid input and clamps to [1s, 10m].
  </behavior>

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-11-06-03 | Spoofing | Demo seed key left in prod | mitigate | Seed only when path unset, with loud warning; invalid path fatal; compose uses distinct keys (Plan 12) |
| T-11-06-04 | Information Disclosure | Key contents in logs | mitigate | Logs carry family and file name only |
| T-11-06-05 | Elevation of Privilege | Stale old key trusted after prune | mitigate | Prune removes file -> next reload (<=interval or SIGHUP) swaps set; test asserts old token rejected |
| T-11-06-06 | Tampering | Reload race with in-flight verify | mitigate | Verifier/validator copy-on-set under RWMutex; -race concurrent test |
