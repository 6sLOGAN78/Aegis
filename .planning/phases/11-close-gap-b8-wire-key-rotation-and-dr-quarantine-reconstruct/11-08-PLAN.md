## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| mounted keyset dir -> verifier | Operator-controlled files become trusted keys |
| gateway -> control plane | Gateway authenticates with its own client cert and verifies the server |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-08-01 | Tampering | Poisoned keyset | mitigate | Reloader rejects partial/empty sets; startup load failure fatal |
| T-11-08-02 | Spoofing | Gateway presenting another gateway's id | mitigate | Id derived from own cert; env override mismatch is fatal |
| T-11-08-03 | Spoofing | MITM of control plane stream | mitigate | RootCAs = Aegis root, ServerName verified, TLS1.3 |
| T-11-08-04 | Elevation of Privilege | Snapshot key defaults to issuer key | mitigate | Separate dirs; fallback env only without dir and with warning (D-09) |
| T-11-08-05 | Denial of Service | Bad keyset at runtime drops auth | mitigate | Last good set retained, metric + log |
| T-11-08-06 | Information Disclosure | Key/cert contents in logs | mitigate | Paths and file names only |
| T-11-08-SC | Tampering | package installs | accept | No new packages |
