<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| key file bytes -> keyfile parser | Untrusted file contents (ConfigMap/Secret mounts) parsed into trusted keys |
| client cert URI SAN -> gateway id | Cert-derived identity becomes an authorisation subject |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01-01 | Spoofing | GatewayIDFromSPIFFE | mitigate | Strict prefix + `^[A-Za-z0-9._-]{1,64}$`; bare backend ID and other trust domains rejected; tests cover traversal chars |
| T-11-01-02 | Tampering | keyfile.Parse* | mitigate | Exact key sizes enforced, wrong key type (RSA) rejected, errors never fall back to a demo seed |
| T-11-01-03 | Information Disclosure | keyfile errors | mitigate | Errors carry path and reason only, never key bytes |
| T-11-01-04 | Tampering | pki.LoadCA | mitigate | Requires IsCA cert and parseable EC key, returns error otherwise |
| T-11-01-05 | Denial of Service | metrics label cardinality | mitigate | Closed label sets, no wire-supplied labels |
| T-11-01-SC | Tampering | package installs | accept | No new packages introduced in this plan (all stdlib or existing go.mod); no install tasks |
</threat_model>
