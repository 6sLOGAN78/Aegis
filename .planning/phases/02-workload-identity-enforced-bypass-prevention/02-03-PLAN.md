# Plan 02-03: Reusable Backend Authentication Middleware and Docker Network Isolation (Zero Published Host Ports)

<threat_model>
### Plan 02-03 STRIDE Threat Analysis

| Threat Category | Specific Threat Scenario | Mitigation in Plan 02-03 Architecture | Verification Mechanism |
|---|---|---|---|
| **Spoofing (S)** | Peer container on the internal Docker bridge (e.g., `orders`) attempts to call `payments` directly, bypassing the gateway and OPA policy. | Backend middleware Layer 1 inspects the peer TLS client certificate and asserts the SPIFFE ID is specifically `spiffe://aegis.local/ns/gateway/sa/aegis-gateway`. Peer containers presenting workload certs or no cert fail with HTTP 403 Forbidden or TLS handshake error (BYP-02, BYP-03, Invariant 12). | Unit tests in `services/middleware/auth_middleware_test.go` asserting rejection of non-gateway peer certificates. |
| **Spoofing (S)** | External adversary connects directly to backend services over unencrypted HTTP without certificates. | Backends listen exclusively on HTTPS with `tls.RequireAndVerifyClientCert`. Plain HTTP connections fail immediately; unauthenticated connections terminate at the TLS layer. | Security tests in `cmd/services/` test suites testing plain HTTP connection rejection. |
| **Tampering (T)** | Attacker mutates HTTP method (e.g. changing `GET` to `POST`) or URL path after an assertion was minted. | Backend middleware Layer 2 verifies the `X-Aegis-Assertion` token against `expectedServiceID`, `r.Method`, and `r.URL.Path`. Method or path mismatches return HTTP 403 Forbidden (BYP-02). | Unit tests in `services/middleware/auth_middleware_test.go` verifying method/path mismatch rejection. |
| **Repudiation (R)** | Backend business handlers execute operations without recording the authenticated principal or correlation ID. | Middleware parses verified `AssertionClaims` and injects them into the standard request context (`FromContext`). Handlers extract `Subject`, `PrincipalKind`, and `RequestID` for audit tracking. | Unit test verifying `FromContext` returns valid claims containing original subject and request ID. |
| **Information Disclosure (I)** | Backend authentication rejections leak internal stack traces or database connection details. | Middleware formats all 401/403 error responses as RFC 7807 problem details with sanitized error summaries (`application/problem+json`). | Test asserting RFC 7807 problem details JSON structure on rejection. |
| **Denial of Service (D)** | Container orchestrator liveness checks fail because `/health` probes cannot provide client certificates or assertions. | Middleware supports configurable path exemptions (`exemptPaths ...string`); `/health` route is exempted from mTLS and assertion verification, enabling reliable container liveness checks. | Test in `services/middleware/auth_middleware_test.go` asserting unauthenticated `/health` requests succeed with HTTP 200 OK. |
| **Elevation of Privilege (E)** | External network caller directly dials backend ports from outside the container network. | Docker Compose configuration defines ZERO published host ports for `orders`, `payments`, and `admin` (`ports:` mapping omitted; only private `expose:` on internal bridge network) (BYP-01, BYP-03). | Compose configuration verification asserting no host port mappings exist for backend services. |
</threat_model>

## Executive Summary

Plan 02-03 establishes the backend defense-in-depth enforcement tier: reusable authentication middleware and strict container network isolation. In a true zero-trust architecture, network location confers zero trust (Invariant 12). Even if an adversary gains execution inside the shared container network or an unprivileged container attempts lateral communication, backend microservices must refuse to process requests that have not been authenticated, authorized, and forwarded by the Aegis Gateway.

Plan 02-03 delivers:
1. Reusable microservice middleware (`services/middleware/auth_middleware.go`) that validates both transport identity (peer client certificate presents Gateway SPIFFE ID `spiffe://aegis.local/ns/gateway/sa/aegis-gateway`) and application assertion (`X-Aegis-Assertion` signed with the Gateway Ed25519 key, matching recipient audience, method, and path).
2. HTTPS mTLS server migration across all three private demo microservices (`orders`, `payments`, `admin`), while exempting `/health` probes for orchestration liveness.
3. A local certificate provisioning CLI (`scripts/certificates/main.go`) generating all required Root CA, gateway, service, workload, and assertion key assets into `deployments/certs/`.
4. Hardened Docker Compose configuration (`docker-compose.mvp.yml`) binding gateway ports 8080 and 9443 while enforcing zero published host ports across all backend microservices.

<acceptance_criteria>
- `services/middleware/auth_middleware.go` exports:
  - `type contextKey string`
  - `const AssertionClaimsKey contextKey = "aegis.assertion_claims"`
  - `BackendAuthMiddleware(authorizedGatewaySPIFFE string, expectedServiceID string, gatewayAssertionPubKey ed25519.PublicKey, exemptPaths ...string) func(http.Handler) http.Handler`
  - `FromContext(ctx context.Context) (*identity.AssertionClaims, bool)`
- Verification logic:
  - If `r.URL.Path` is in `exemptPaths` (e.g. `/health`), proceeds directly to `next.ServeHTTP(w, r)`.
  - Layer 1 (Transport):
    - Asserts `r.TLS != nil` and `len(r.TLS.PeerCertificates) > 0`; if missing, writes RFC 7807 problem details with HTTP 401 Unauthorized and detail "mTLS client certificate required".
    - Extracts SPIFFE ID via `identity.ExtractSPIFFEID(peerCert, "aegis.local")`.
    - If error or `spiffeID != authorizedGatewaySPIFFE`, writes RFC 7807 problem details with HTTP 403 Forbidden and detail "unauthorized client identity: peer is not the Aegis Gateway".
  - Layer 2 (Application):
    - Checks header `X-Aegis-Assertion`; if empty, writes RFC 7807 problem details with HTTP 401 Unauthorized and detail "missing required X-Aegis-Assertion header".
    - Verifies token via `verifier.VerifyAssertion(assertionHeader, r.Method, r.URL.Path)`.
    - If verification fails (signature, audience, method, path, expiry), writes RFC 7807 problem details with HTTP 403 Forbidden and detail including validation error.
  - Context propagation: stores verified `*identity.AssertionClaims` into `r.Context()` under `AssertionClaimsKey` and invokes `next.ServeHTTP`.
- Unit tests in `services/middleware/auth_middleware_test.go` test:
  - Unauthenticated plain HTTP connection (r.TLS == nil) returns HTTP 401.
  - Connection with peer certificate from peer workload (`spiffe://aegis.local/workload/orders`) returns HTTP 403.
  - Connection with gateway client cert but missing `X-Aegis-Assertion` header returns HTTP 401.
  - Connection with gateway client cert but assertion with mismatched audience returns HTTP 403.
  - Connection with gateway client cert but assertion with mismatched method returns HTTP 403.
  - Connection with gateway client cert but assertion with mismatched path returns HTTP 403.
  - Valid connection with gateway client cert and matching assertion returns HTTP 200 with claims in context.
  - Unauthenticated request to exempt path (`/health`) returns HTTP 200.
- Unit test command exits with code 0:
  `go test -v -race ./services/middleware/ -run TestAuthMiddleware`
</acceptance_criteria>

   - Declare package `middleware`.
   - Import `context`, `crypto/ed25519`, `encoding/json`, `net/http`, `aegis/internal/identity`.
   - Define `type contextKey string` and `const AssertionClaimsKey contextKey = "aegis.assertion_claims"`.
   - Implement `BackendAuthMiddleware(authorizedGatewaySPIFFE string, expectedServiceID string, gatewayAssertionPubKey ed25519.PublicKey, exemptPaths ...string) func(http.Handler) http.Handler`:
     - Construct `verifier := identity.NewAssertionVerifier(gatewayAssertionPubKey, expectedServiceID)`.
     - Build lookup map `exemptMap := make(map[string]bool)` from `exemptPaths`.
     - Return middleware function wrapping `next http.Handler`:
       - Check `exemptMap[r.URL.Path]`: if true, call `next.ServeHTTP(w, r)` and return.
       - Check `r.TLS == nil || len(r.TLS.PeerCertificates) == 0`: call `writeError(w, http.StatusUnauthorized, "mTLS client certificate required")` and return.
       - Extract peer cert `peerCert := r.TLS.PeerCertificates[0]`.
       - Call `spiffeID, err := identity.ExtractSPIFFEID(peerCert, "aegis.local")`.
       - If `err != nil || spiffeID != authorizedGatewaySPIFFE`: call `writeError(w, http.StatusForbidden, "unauthorized client identity: peer is not the Aegis Gateway")` and return.
       - Check `assertionHeader := r.Header.Get("X-Aegis-Assertion")`: if empty, call `writeError(w, http.StatusUnauthorized, "missing required X-Aegis-Assertion header")` and return.

       - Inject claims: `ctx := context.WithValue(r.Context(), AssertionClaimsKey, claims)`.
       - Call `next.ServeHTTP(w, r.WithContext(ctx))`.
