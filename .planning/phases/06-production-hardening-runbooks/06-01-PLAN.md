# Plan 06-01: Kubernetes Production Reference Manifests with Default-Deny NetworkPolicies and Non-Root Security Contexts

<threat_model>
### Plan 06-01 STRIDE Threat Analysis

| Threat Category | Specific Threat Scenario | Mitigation in Plan 06-01 Architecture | Verification Mechanism |
|---|---|---|---|
| **Spoofing (S)** | Unauthenticated adjacent container spoofing external user or backend identity over cluster network. | Invariant 12 enforcement: Cluster network proximity confers zero trust. Default-deny `NetworkPolicies` isolate `aegis-system` and `aegis-apps`. Backend services accept ingress strictly from pods with label `app: aegis-gateway` on port 8443 with mTLS. | Automated manifest AST inspection in `tests/manifests/manifest_test.go` asserting ingress pod selectors and ports. |
| **Tampering (T)** | Attacker gaining pod execution tampers with local root filesystem binaries or dynamic libraries. | Kubernetes Pod Security Standard (Restricted profile) enforces `readOnlyRootFilesystem: true`, non-root user `runAsUser: 10001`, and dropped Linux capabilities (`drop: ["ALL"]`). Writable directories are isolated to dedicated PVCs (`/var/log/aegis/wal`) and memory `emptyDir` (`/tmp`). | Automated manifest test verifying container `securityContext.readOnlyRootFilesystem == true` and `securityContext.capabilities.drop == ["ALL"]`. |
| **Repudiation (R)** | Pod termination drops uncommitted WAL records because storage was ephemeral or shared. | Gateway uses `StatefulSet` with `volumeClaimTemplates` provisioning an isolated `ReadWriteOnce` SSD PVC per replica (`wal-spool-aegis-gateway-0`), preventing multi-attach volume locking bugs and surviving pod restarts. | Automated manifest test asserting StatefulSet kind, volumeClaimTemplates definition, and mount path `/var/log/aegis/wal`. |
| **Information Disclosure (I)** | Unrestricted egress allows compromised container to exfiltrate tokens, certificates, or keys to external IP addresses. | Egress `NetworkPolicy` explicitly restricts outbound traffic to verified cluster endpoints (Redis :6379, Control Plane :9090, Backend pods :8443, and CoreDNS :53 UDP/TCP). All other external and internal outbound traffic is dropped. | Automated manifest test validating egress whitelist rules and explicit CoreDNS port 53 UDP/TCP permit. |
| **Denial of Service (D)** | Cluster node drain, maintenance, or rolling update terminates multiple gateway replicas simultaneously. | `PodDisruptionBudget` specifies `minAvailable: 2` out of 3 replicas. Cross-zone `topologySpreadConstraints` mandate distribution across failure domains (`topology.kubernetes.io/zone` and `kubernetes.io/hostname`). | Automated manifest test verifying `PodDisruptionBudget` `minAvailable: 2` and production overlay topology spread rules. |
| **Elevation of Privilege (E)** | Container process escalates privileges via setuid binaries or host namespaces. | Container security context mandates `allowPrivilegeEscalation: false`, `runAsNonRoot: true`, and `seccompProfile.type: RuntimeDefault`. Host networking, host PID, and host IPC namespaces are strictly prohibited. | Automated manifest test asserting `allowPrivilegeEscalation == false`, `runAsNonRoot == true`, and absence of host namespaces. |
</threat_model>

## Executive Summary

Plan 06-01 establishes production-grade Kubernetes reference manifests for the entire Aegis architecture (K8S-01), translating the distributed zero-trust design into declarative Kustomize infrastructure. It implements isolated `aegis-system` and `aegis-apps` namespaces guarded by the Kubernetes Pod Security Standard (Restricted profile).

To solve local storage isolation without multi-attach volume lockup across multi-node clusters, the gateway data plane is structured as a `StatefulSet` with dedicated `volumeClaimTemplates` for local append-only WAL spools. Every workload declares non-root execution (`runAsUser: 10001`), read-only root filesystems, and dropped capabilities (`drop: ["ALL"]`). Strict default-deny `NetworkPolicies` eliminate flat-network trust: backends accept traffic exclusively from gateway pods over mTLS, while gateway egress is whitelisted strictly to backends, Redis, Control Plane, and CoreDNS (port 53 UDP/TCP). A production overlay introduces cross-zone topology spread constraints and `PodDisruptionBudget` (`minAvailable: 2`), backed by an automated Go manifest validation test suite and Dockerized kubectl verification targets.
