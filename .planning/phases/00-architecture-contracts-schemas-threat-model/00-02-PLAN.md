# Plan 00-02: OpenAPI 3.0 Management Specification & Protobuf Snapshot Distribution Schemas

<threat_model>
### Plan 00-02 STRIDE Threat Analysis

| Threat Category | Specific Threat Scenario | Mitigation in Plan 00-02 Contracts | Verification Mechanism |
|---|---|---|---|
| **Spoofing (S)** | Unauthenticated callers invoke control plane APIs or gateway connects to unverified gRPC stream. | OpenAPI requires explicit RBAC permission scopes on all endpoints; Protobuf envelope includes `signing_key_id` verified against pinned trusted control-plane keys. | OpenAPI security scheme definition and Protobuf envelope verification. |
| **Tampering (T)** | In-transit snapshot tampering or signature invalidation due to non-deterministic field ordering. | Protobuf `SnapshotEnvelope` separates raw `payload` bytes from `payload_sha256` digest and signs the SHA-256 digest with Ed25519, preventing JSON/Protobuf re-ordering mismatch. | Protobuf schema compilation and Ed25519 signature payload hashing test. |
| **Repudiation (R)** | Operator performs policy publish or emergency quarantine without traceable audit metadata. | OpenAPI operations mandate `Idempotency-Key` and return RFC 3339 UTC timestamps and correlation UUIDs; mutation endpoints record actor context. | Redocly schema validation asserting `Idempotency-Key` header parameter. |
| **Information Disclosure (I)** | Management error responses expose private keys, database connection strings, or internal stack traces. | OpenAPI models standard `ErrorResponse` component with discrete error codes and human-readable messages, explicitly omitting sensitive system internals. | Redocly lint checking error response references across all status codes. |
| **Denial of Service (D)** | Unbounded request payload sizes or unbounded pagination queries exhaust control plane memory. | OpenAPI schemas define explicit `maxLength`, `maxItems`, and pagination limits (`maximum: 200` on route listings). | Redocly lint asserting schema constraint completeness. |
| **Elevation of Privilege (E)** | Data-plane caller accesses management endpoints without administrative privileges. | Separate `/control/v1` namespace with discrete permission scopes (`policy.publish`, `security.respond`, `configuration.write`) defined in OpenAPI contracts. | OpenAPI security requirement declarations per operation. |
</threat_model>

## Executive Summary

Plan 00-02 establishes the authoritative schema contracts for Aegis. It defines the OpenAPI 3.0.3 REST management specification (`api/openapi/control-v1.yaml`) modeling all 13 `/control/v1` routes with optimistic concurrency (`ETag`/`If-Match`), idempotency tokens, and RFC 7807-style error responses. It defines the Protocol Buffers 3 contract (`api/proto/snapshot/v1/snapshot.proto`) modeling monotonic signed snapshot envelopes, route catalogs, 10-second freshness leases, acknowledgments, and bidirectional gRPC streaming. Finally, it creates the code generation pipeline (`scripts/generate.sh`) compiling these schemas into strongly typed Go packages (`pkg/api/control/v1` and `pkg/api/snapshot/v1`) verified by static analysis.

3. Author `scripts/generate.sh`:
   ```bash
   #!/usr/bin/env bash
   set -euo pipefail

   SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
   ROOT_DIR="$(cd "${SCRIPT_DIR}/.." && pwd)"

   echo "=== Generating Protobuf Go Stubs ==="
   mkdir -p "${ROOT_DIR}/pkg/api"
   INCLUDE_ARGS=()
   if [ -d "${HOME}/.local/include" ]; then
     INCLUDE_ARGS+=("-I" "${HOME}/.local/include")
   fi
   protoc --proto_path="${ROOT_DIR}/api/proto" "${INCLUDE_ARGS[@]}" \
     --go_out="${ROOT_DIR}/pkg/api" --go_opt=paths=source_relative \
     --go-grpc_out="${ROOT_DIR}/pkg/api" --go-grpc_opt=paths=source_relative \
     "${ROOT_DIR}/api/proto/snapshot/v1/snapshot.proto"

   echo "=== Generating OpenAPI Go Types ==="
   mkdir -p "${ROOT_DIR}/pkg/api/control/v1"
   oapi-codegen -generate types -package controlv1 \
     "${ROOT_DIR}/api/openapi/control-v1.yaml" > "${ROOT_DIR}/pkg/api/control/v1/types.gen.go"

   echo "=== Verifying Generated Code ==="
   go vet "${ROOT_DIR}/pkg/api/..."
   echo "=== Code Generation Succeeded ==="
   ```
4. Set execution permissions: `chmod +x scripts/generate.sh`.
5. Execute `scripts/generate.sh` to produce the generated Go files and run `go mod tidy`.
