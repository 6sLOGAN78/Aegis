# Plan 03-02: Monotonic Ed25519 Snapshot Signer, gRPC Streaming, 10s Freshness Lease, and 60s Fail-Closed Timeout

<threat_model>
### Plan 03-02 STRIDE Threat Analysis

| Threat Category | Specific Threat Scenario | Mitigation in Plan 03-02 Architecture | Verification Mechanism |
|---|---|---|---|
| **Spoofing (S)** | Attacker tampers with snapshot payload or freshness lease during gRPC transit from Control Plane to Gateway. | Control plane signs the SHA-256 digest of snapshot payload and lease metadata with Ed25519 private key; gateway verifies signature against pinned public key before activation (CTRL-02, CTRL-04, Invariant 4). | Unit and integration tests injecting modified payload bytes or forged signatures; assert gateway rejects with `ACK_STATUS_REJECTED`. |
| **Tampering (T)** | Attacker replays an older configuration snapshot with revoked permissions (Rollback Attack). | Gateway verifies strictly increasing monotonic integer version (`incoming.Version > current.Version`); older or equal versions are rejected. Control plane rollbacks republish historical configuration under strictly higher version $N+1$ (CTRL-02, CTRL-06, Invariant 9). | Unit test in `internal/snapshot/signer_test.go` attempting to activate snapshot version $\le N$; assert version rejection and retention of active state. |
| **Repudiation (R)** | Gateway activates or rejects a snapshot without the control plane knowing its convergence state. | Gateway emits typed `SnapshotAck` messages (`ACK_STATUS_ACTIVATED` or `ACK_STATUS_REJECTED`) containing active version and error details over the bidirectional gRPC stream; control plane persists status to PostgreSQL (CTRL-05). | Integration test asserting `SnapshotAck` receipt and database convergence status. |
| **Information Disclosure (I)** | Unauthenticated observer snooping on gRPC configuration stream. | gRPC distribution service enforces mutual TLS (`SnapshotDistributionService.StreamSnapshots`) with pinned certificates and private network deployment. | Test verifying gRPC connections without trusted TLS certificates are rejected during handshake. |
| **Denial of Service (D)** | gRPC streaming connection drops due to network hiccup or control plane restart. | Gateway gRPC client implements randomized exponential reconnect backoff with jitter (`base: 100ms`, `max: 5s`, `factor: 1.5`, `jitter: 0.2`) to prevent thundering herds on reconnect. | Reconnect test dropping server connection and verifying automatic reconnection with jitter. |
| **Elevation of Privilege (E)** | Partitioned gateway continues serving traffic indefinitely against stale policy after privileges are revoked. | Control plane streams signed `FreshnessLease` messages every 10 seconds. If a gateway fails to receive a verified lease renewal for >60 seconds, it drops readiness (`/healthz/ready`) and fails closed with HTTP 503 (`POLICY_LEASE_EXPIRED`) on all protected routes (CTRL-04, Invariant 1, ADR-0004). | Security failure test in `tests/failure/lease_expiry_test.go` asserting HTTP 503 response when lease age exceeds 60 seconds. |
</threat_model>

## Executive Summary

Plan 03-02 implements the central policy distribution backbone connecting the Aegis Control Plane to Gateway data plane replicas. Grounded in ADR-0004 and Invariants 1 and 9, configuration state is distributed as digitally signed, monotonically versioned snapshots over persistent bidirectional gRPC streams (`SnapshotDistributionService`).

To eliminate lock contention and avoid intermediate routing anomalies on the request hot path, the gateway parses snapshots out-of-band, precompiles Rego queries via embedded OPA, and executes an atomic in-memory swap using `sync/atomic.Pointer[ActiveState]`. To prevent partitioned replicas from serving stale policy indefinitely, the control plane issues signed 10-second freshness leases; if a gateway loses contact with the control plane for >60 seconds, it drops readiness and fails closed with HTTP 503. Monotonic rollbacks republish historical configurations under strictly higher version numbers ($N+1$).

    - Serializes payload using `proto.Marshal`.
    - Computes hex-encoded SHA-256 checksum of payload bytes.
    - Signs the hex SHA-256 string using `ed25519.Sign`.
    - Returns `*snapshotv1.SnapshotEnvelope` with `Version: payload.Version`, `PayloadSha256`, `Signature`, `SigningKeyId`, `CreatedAt`, `ExpiresAt`.

    - Signs lease content digest and returns `*snapshotv1.FreshnessLease`.
- `internal/snapshot/verifier.go` exports:
  - `Verifier` struct initialized with trusted `ed25519.PublicKey`.
  - `VerifySnapshot(env *snapshotv1.SnapshotEnvelope, currentVersion int64) (*snapshotv1.SnapshotPayload, error)`:
    - Enforces monotonic version: if `env.Version <= currentVersion`, returns error wrapping `ErrMonotonicVersionViolation`.
    - Calculates SHA-256 digest of `env.Payload` bytes; returns error if does not match `env.PayloadSha256`.
    - Verifies Ed25519 signature of `env.PayloadSha256` using trusted public key; returns `ErrInvalidSignature` on failure.
    - Unmarshals `env.Payload` into `snapshotv1.SnapshotPayload` and validates version matches envelope.
  - `VerifyLease(lease *snapshotv1.FreshnessLease, expectedVersion int64) error`:
    - Validates signature and asserts lease is not expired and matches expected snapshot version.
- `internal/control/rollback.go` exports:
  - `RollbackEngine` struct wrapping `SnapshotRepo` and `Signer`.
  - `RollbackToVersion(ctx context.Context, targetVersion int64, publishedBy string) (*snapshotv1.SnapshotEnvelope, error)`:
    - Fetches target snapshot content from repository.
    - Fetches currently active latest version $N$.
    - Assigns strictly higher monotonic version $N+1$ to the new snapshot payload (CTRL-06).
    - Mints and signs new snapshot envelope with version $N+1$ containing the historical content.
    - Saves new snapshot envelope to repository.

## Must-Haves
### Truths
- Configuration snapshots are digitally signed with Ed25519 over payload SHA-256 and enforce strictly increasing monotonic integer version numbers.
- Gateways reject any snapshot with `version <= current_version` or invalid signature, preserving the active state without interruption.
- Policy rollbacks republish historical configuration under a strictly higher monotonic version number ($N+1$).
- Gateway activates snapshots atomically via `sync/atomic.Pointer[ActiveState]` after out-of-band validation and Rego precompilation.
- Control plane streams signed freshness leases every 10 seconds; if a gateway loses lease renewal for >60 seconds, it fails closed (HTTP 503 `POLICY_LEASE_EXPIRED`).
- Gateways report activation acknowledgments (`SnapshotAck`) back to the control plane for fleet convergence tracking.
- The control plane daemon binary (`cmd/control-plane/main.go`) initializes database pooling, key signing, lease generation, and gRPC distribution on port `:9090`.
- The gateway daemon binary (`cmd/gateway/main.go`) wires dynamic snapshot management and gRPC streaming, failing closed on expired leases or uninitialized state.
