<objective>
Build the in-memory admission policy for denial records: which denials are written, which are counted instead, and which are dropped. One suppression mechanism handles all identified-principal denials and the anonymous fail-closed 503s; one token-bucket mechanism caps unauthenticated rejections. Both are deterministic under an injected clock.

Purpose: D-04, D-05, D-06, D-13, D-14 and D-15 together define who may consume spool capacity. Without this, any valid token holder could fill the spool with identical 404/403 rows and halt allowed traffic at the 90 percent gate, and an outage (Redis down, stale lease) would turn every request into an fsynced record.
Output: governor.go, its tests, and the drift guard that keeps the classification honest as main.go evolves.
</objective>

New contract produced here and consumed by plan 07 (names load-bearing):
- type Disposition int with constants Record, Suppress, Drop
- type GovernorConfig struct { SuppressWindow time.Duration; MaxKeys int; UnauthRate float64; UnauthBurst int }
- type Admission struct { Disposition Disposition; Label string; Overflow bool }   (Label = closed-set reason label for the metrics counter; Overflow true when the suppressor map was full and the event was routed to the per-label overflow bucket - the disposition is then Record for the bucket's first event in the window and Suppress for the rest, never an unconditional Record)
- func NewGovernor(cfg GovernorConfig) *Governor
- func (g *Governor) Admit(ev *CompletionEvent, now time.Time) Admission
- func (g *Governor) Sweep(now time.Time) []*CompletionEvent   (summary events for windows that closed at or before now with count > 0 - from both the keyed map and the overflow buckets - plus summaries stashed when Admit found an expired window; deletes closed entries; entries with count 0 expire silently)
- func (g *Governor) Flush(now time.Time) []*CompletionEvent   (shutdown: summaries for EVERY open window with count > 0, then clears the map)
- func ReasonLabel(reason string) string      (closed set; unknown or empty maps to "OTHER")
- func ClosedReasonLabels() []string          (all labels including "OTHER", sorted; main passes it to telemetry.InitAuditSuppressedLabels)
