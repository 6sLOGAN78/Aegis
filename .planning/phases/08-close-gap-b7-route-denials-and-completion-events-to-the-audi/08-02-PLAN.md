Purpose: D-07/D-08 need group commit, D-11 needs headroom between 90 and 95 percent that only denials and completions may use, and D-12 needs a way to stop allowed traffic when audit is losing data. The host root filesystem is 88-99 percent used, so every new test must inject the quota and statfs.
Output: spool.go additions and spool_group_test.go. No other file changes in this plan.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| gateway process -> local disk | audit frames must reach non-volatile storage without corrupting prior records |
| unauthenticated traffic -> spool capacity | flooding can consume the disk that allowed traffic needs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-06 | Denial of service | audit-log flooding fills the spool and halts allowed traffic | mitigate | hard limit (default 0.95) caps headroom writes; WriteFrames returns ErrHardLimit and writes nothing; governor and queue bounds are added in later plans |
| T-08-07 | Tampering / Repudiation | torn batch write leaves garbage between valid frames and makes the reader skip a valid record | mitigate | single Write per batch, Truncate back to the last good size on error, rotate if truncate fails (TestWriteFramesFailureTruncates) |
| T-08-08 | Elevation of privilege (weakened guarantee) | new write path weakens the pre-forward fsync or 90 percent gate | mitigate | AppendPreForward body hash-checked unchanged (D-09); WriteFrames never calls CheckSaturation; AppendPreForward still fsyncs synchronously |
| T-08-09 | Denial of service | fault flag stuck set makes the gateway permanently 503 | mitigate | ClearWriteFault exists and is driven by the committer's recovery ticker in plan 06; the flag is an atomic, no lock inversion with s.mu |
| T-08-10 | Information disclosure | frames contain request fields | accept | same fields already spooled for allow rows; callers Normalize before framing (plans 05 and 06); no secrets or bearer tokens are in CompletionEvent |
