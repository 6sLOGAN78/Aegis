<objective>
Hook the durable audit sink into the request path at the one point that sees final decision, reason, principal and status: the audit middleware. Denials are handed to the sink at the first response WriteHeader (before any byte reaches the client); completions are handed over in the existing defer; upstream failures get error codes; the decision-flip bug is fixed; durable events are typed and normalized.

Purpose: every denial exit in cmd/gateway/main.go sets ac.SetDecision/SetErrorCode and then calls proxy.WriteProblemDetails, which calls WriteHeader before writing the body, so a single hook covers all ~30 exits with no per-exit edits (research Pattern 1). This plan defines the Sink interface; plan 07 supplies the implementation.
Output: logger.go changes and tests only.
</objective>

New contract (names load-bearing; plan 07's Pipeline implements Sink):
- type Sink interface { RecordDenial(ev *CompletionEvent); EnqueueCompletion(ev *CompletionEvent) }
  RecordDenial may block briefly until the record is durable (or dropped/suppressed) and must never panic; EnqueueCompletion must be non-blocking.
- type Option func(*middlewareConfig); func WithSink(s Sink) Option
- func AuditMiddleware(logger *Logger, snapshotVersion int64, opts ...Option) func(http.Handler) http.Handler
- func WrapUpstreamErrorHandler(next func(http.ResponseWriter, *http.Request, error)) func(http.ResponseWriter, *http.Request, error)
- AuditContext gains unexported decisionSet bool (set by SetDecision) and durableRecorded bool.
</interfaces>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client request -> AuditContext -> durable record | decoded URL path, HTTP method, client-chosen strings flow into spool rows |
| middleware -> sink | the sink may block (denial) or drop; request handling must stay correct either way |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-22 | Tampering | NUL byte or oversize method/path in a durable row poisoning the worker | mitigate | Normalize() on every durable copy at record construction (D-18); stdout copy unchanged; tested with NUL path and 28-char method |
| T-08-23 | Repudiation | denial not recorded because the response is sent first | mitigate | hook runs before ResponseWriter.WriteHeader; TestDenialRecordedBeforeResponse proves ordering (D-07) |
| T-08-24 | Repudiation | backend failure recorded as a policy denial (decision flip) | mitigate | decisionSet makes the handler's explicit decision authoritative; TestCompletionKeepsAllowOnBackendError |
