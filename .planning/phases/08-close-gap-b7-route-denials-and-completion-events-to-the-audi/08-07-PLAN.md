## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| request path -> pipeline | every denied request reaches RecordDenial; volume and content are attacker-influenced |
| pipeline -> shutdown | in-flight records at process exit |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-36 | Denial of service | denial flood makes request goroutines wait on fsync | mitigate | suppressed and dropped denials return immediately; recorded ones share fsyncs via the committer; waiter timeout 2s |
| T-08-37 | Repudiation | summary rows lost at shutdown | mitigate | Shutdown flushes every open window into the committer before it stops intake, then drains inside the deadline (TestPipelineShutdown, TestE2ESuppressionAndSummary) |
| T-08-38 | Tampering | hostile method/path values wedge the worker | mitigate | normalization at middleware, committer and worker; TestE2EPoisonNormalized and the worker delivery test |
