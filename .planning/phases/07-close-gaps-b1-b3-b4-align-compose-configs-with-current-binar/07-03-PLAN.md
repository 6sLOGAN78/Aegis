## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host -> gateway (8080/9443) | The only user-facing ports in mvp; backends must stay unreachable from the host (BYP-01) |
| gateway -> control-plane gRPC / Redis | Snapshot and revocation lookups; must be explicit, never `localhost:*` defaults |
| compose env -> containers | DB and operator demo credentials |
| gateway/audit-worker -> shared WAL volume | Spool is private to one gateway and one worker |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-11 | Elevation / Spoofing (fail-open drift) | Gateway or control plane falling back to localhost:9090 / localhost:6379 inside a container | mitigate | Explicit AEGIS_CONTROL_PLANE_GRPC_ADDR and AEGIS_REDIS_ADDR on gateway, AEGIS_REDIS_ADDR on control-plane; asserted by TestGatewayWiring and TestControlPlaneHasRedis. Fail-closed behavior is unchanged (no Go change). |
| T-07-12 | Elevation (bypass) | Publishing backends, control plane, Redis or Postgres to the host | mitigate | mvp publishes only gateway 8080/9443 and demo-issuer 8085; backends use `expose`; TestMVPTopology and the live TestBackendBypassPrevention assert this. Hardened keeps its pre-existing 8084/9090 publication (existing tech debt, unchanged, flagged for a later phase). |
| T-07-13 | Information disclosure | DB password aegis-secret-pw and operator admin-secret in compose env | accept | Existing demo values already in these files and internal/control/auth.go (known tech debt); no new secret, nothing marked production; comment added on the seed env. |
| T-07-14 | Repudiation | Audit WAL lost on SIGKILL during drain | mitigate | stop_grace_period 45s >= AEGIS_DRAIN_TIMEOUT 30s + 5s metrics shutdown + margin (A5: derived from code, measured in plan 07-06). |
