# Plan 04-02: React/TypeScript Operator Dashboard with Monaco Rego Editor, Dry-Run Simulator, and Audit Log Viewer

<threat_model>
### Plan 04-02 STRIDE Threat Analysis

| Threat Category | Specific Threat Scenario | Mitigation in Plan 04-02 Architecture | Verification Mechanism |
|---|---|---|---|
| **Spoofing (S)** | Unauthenticated browser client accesses operational management views or spoofs operator role badge. | `Shell.tsx` and `App.tsx` query `GET /control/v1/auth/me` on mount; if unauthorized, displays modal login overlay (`LoginModal`). The displayed operator role badge is derived strictly from server session data, and mutating controls are disabled for non-privileged roles. | E2E browser tests and API client tests asserting 401 triggers login overlay. |
| **Tampering (T)** | Cross-Site Scripting (XSS) via injected script tags in Rego source code, audit event paths, or principal IDs. | React JSX automatically encodes all interpolated strings; Monaco Editor treats Rego code as pure text in a secure sandboxed text model; strict CSP headers (`script-src 'self' 'unsafe-eval' blob:; object-src 'none'`) prevent remote script injection or inline execution from untrusted origins. | Automated build check asserting zero unescaped `dangerouslySetInnerHTML` usage. |
| **Tampering (T)** | External CDN supply chain attack via third-party asset loading (e.g. Monaco or Tailwind loaded from unpinned CDNs). | All packages (`react`, `vite`, `tailwindcss`, `@monaco-editor/react`, `monaco-editor`, `lucide-react`) are bundled locally via Vite. Zero external CDN calls (`script-src 'self'`). Monaco web workers load locally via `blob:` URLs conforming to CSP. | Vite production build assertion verifying zero external script dependencies. |
| **Repudiation (R)** | Operator publishes policies without reviewing diffs or recording publication intent. | Policy Studio modal displays current version ($N$), next monotonic version ($N+1$), ETag hash, and requires a mandatory or structured publish comment recorded in the snapshot metadata. | Component tests verifying publish dialog contains version progression and comment fields. |
| **Information Disclosure (I)** | Audit log inspection drawer leaks raw tokens or sensitive headers to unauthorized console viewers. | UI renders structured JSON event attributes with sensitive authorization tokens scrubbed or masked; audit inspection access is restricted to `sec-ops` and `auditor` roles. | Component verification asserting token scrubbing in event drawer view. |
| **Denial of Service (D)** | Loading tens of thousands of audit records causes browser DOM freeze and browser tab crash. | `AuditStream.tsx` enforces cursor-based pagination (default 50 records per page), bounding DOM node count; queries default to 24-hour time ranges to prevent excessive database scans. | Frontend build and pagination unit verification. |
| **Elevation of Privilege (E)** | Operator with `viewer` role activates "Publish Policy Snapshot" button in UI. | `PolicyStudio.tsx` inspects active session role and hides/disables publishing action buttons if role is not `sec-ops`; server-side RBAC middleware provides secondary defense-in-depth returning 403 Forbidden. | Component tests asserting disabled buttons for `viewer` and `auditor` roles. |
</threat_model>

## Executive Summary

Plan 04-02 delivers the modern, high-density React 19 / TypeScript operator dashboard (`web/dashboard`) and embedded Go SPA server (`internal/control/spa.go`). In accordance with OPS-03, OPS-04, and the Phase 4 UI Specification (`04-UI-SPEC.md`), the console provides security operators with an intuitive dark SOC interface for Rego policy authoring, live syntax validation, dry-run simulation, and historical audit log inspection.

This plan scaffolds the frontend application using Vite 8 and Tailwind CSS v4, implements a robust API client with automatic session credential management and CSRF token propagation, constructs a custom Monaco Monarch tokenizer for Rego v1 syntax highlighting, delivers the Policy Studio with monotonic publishing confirmation dialogs, builds the side-by-side Policy Simulator with microsecond latency badges, provides the filterable PostgreSQL Audit Stream viewer with slide-over JSON drawers, and wires the embedded Go file server with a build placeholder ensuring seamless compilation across development and CI.
