# Phase 4 — UI Design Contract

> Visual and interaction contract for the Aegis Operator Dashboard (`web/dashboard`). Generated by gsd-ui-researcher, consumed by gsd-planner and gsd-executor, verified by gsd-ui-checker.

---

## Design System

| Property | Value | Source / Rationale |
|----------|-------|--------------------|
| **Tool** | none | Pure Tailwind CSS v4 design system with `@tailwindcss/vite` |
| **Preset** | not applicable | Standalone utility-first architecture without shadcn CLI preset |
| **Component library** | none (Tailwind CSS v4 utility components) | Zero third-party component dependencies; native HTML5 + accessible ARIA |
| **Icon library** | `lucide-react` (v1.52.0) | Cybersecurity and operational SVG icons (Shield, Play, AlertTriangle, CheckCircle2, XCircle, RefreshCw, Clock, Key, Ban) |

| **Font (UI Text)** | `Inter`, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif | Clean, legible sans-serif for operational telemetry and status indicators |
| **Font (Code & Tokens)** | `JetBrains Mono`, "SF Mono", Menlo, Consolas, monospace | Tabular, monospaced typography for Rego rules, JSON context, UUIDs, and digests |

## Spacing Scale

Declared values strictly adhere to the 4-point grid (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| **xs** | 4px | Icon gaps, badge internal padding, inline badge margins |
| **sm** | 8px | Button vertical padding, compact form gaps, input field padding, table cell vertical padding |
| **md** | 16px | Card internal padding, standard form grid gaps, table cell horizontal padding |
| **lg** | 24px | Section padding, modal header spacing, panel container gaps |
| **xl** | 32px | Major layout gaps, sidebar navigation width offset, top navigation margins |
| **2xl** | 48px | Major section breaks, card grid row gaps |
| **3xl** | 64px | Page-level outer container padding, view boundary spacing |

**Exceptions:** none (Strict 4-point grid alignment maintained across all containers and interactive elements).

## Typography

To eliminate visual noise and maintain a disciplined cybersecurity aesthetic, the typography scale is strictly constrained to **4 font sizes** and **2 font weights**:

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| **Display** | 24px (`text-2xl`) | 600 (`font-semibold`) | 1.25 (`leading-tight`, 30px) | Top-level dashboard screen titles, hero metrics, modal headings |
| **Heading** | 18px (`text-lg`) | 600 (`font-semibold`) | 1.3 (`leading-snug`, 24px) | Card titles, panel section headings, table headers, drawer titles |
| **Body** | 14px (`text-sm`) | 400 (`font-normal`) | 1.5 (`leading-normal`, 21px) | Table row cells, description paragraphs, form inputs, JSON editor body |
| **Label** | 12px (`text-xs`) | 600 (`font-semibold`) | 1.4 (`leading-none`, 17px) | Status badges, role tags, reason codes, timestamps, lease counters, column captions |

**Declared Font Weights (exactly 2):**
1. **Regular (400)**: Used for all reading text, form inputs, table data, and descriptions.
2. **Semibold (600)**: Used for all headings, labels, button text, table headers, and status badges.

   - **Primary Visual Anchor**: The high-visibility red banner and warning icon (`AlertTriangle`) stating "IMMEDIATE CLUSTER-WIDE BLOCK IN <5s".

## Copywriting Contract

### Primary Action Call-to-Actions (CTAs)
Every action button uses an explicit `[Verb] + [Noun]` pattern:

| Screen / Modal | Button Copy | Intent & Behavior |
|----------------|-------------|-------------------|
| Policy Studio | `Publish Policy Snapshot` | Opens monotonic confirmation modal for snapshot publication ($N+1$) |
| Policy Studio | `Validate Rego Syntax` | Triggers in-memory OPA AST compilation and embedded unit test suite |
| Policy Simulator | `Execute Dry-Run Simulation` | Evaluates synthetic request context against candidate Rego code |
| Convergence View | `Refresh Fleet Status` | Refetches `/control/v1/gateways` replica convergence metrics |
| Audit Stream | `Filter Audit Events` | Submits timestamp, principal, route, and decision filters to PostgreSQL |
| Audit Stream | `Export Audit Records` | Downloads filtered audit events as newline-delimited JSON |
| Emergency Modal | `Confirm Quarantine Block` | Posts principal ID to Redis blocklist with mandatory reason |
| Revocation Modal | `Execute Token Revocation` | Invalidates token `jti` in Redis with TTL |
| Rollback Modal | `Execute Version Rollback` | Republishes historical snapshot under monotonic version $N+1$ |
| Operator Shell | `Authenticate Operator Session` | Submits operator credentials and establishes HttpOnly cookie |
| Operator Shell | `Terminate Operator Session` | Clears session cookie and invalidates server session |

### Error State Copy Contract
Every error message pairs an explicit problem diagnosis with an actionable solution path:

| Failure Scenario | Problem Description | Solution Path |
|------------------|---------------------|---------------|
| **Concurrent Edit Conflict (HTTP 412)** | `Snapshot Publication Conflict (ETag Mismatch)` | `Another operator published a new policy version (v43) while you were editing. Reload the active version, reconcile your changes, and republish.` |
| **Duplicate Idempotency Key (HTTP 409)** | `Publication Request In Progress` | `A concurrent publishing request is already processing with this idempotency key. Wait for confirmation or refresh the version log.` |
| **Session Expired / CSRF Error (HTTP 403)** | `Operator Session Expired or CSRF Token Invalid` | `Your authenticated operator session has expired or the security token mismatch occurred. Re-authenticate to resume administrative actions.` |
| **Rego Syntax Compilation Error (HTTP 400)** | `Rego AST Compilation Failed` | `Line 14: syntax error: unexpected identifier, expected 'if' or rule body. Review Rego v1 syntax rules and re-run validation.` |
| **Redis Quarantine Timeout (HTTP 503)** | `Quarantine Propagation Failed (Redis Timeout >200ms)` | `The control plane failed to reach the shared Redis cluster within the 200ms SLA. Verify Redis cluster status; fail-closed safety preserved.` |
| **PostgreSQL Partition Query Error (HTTP 500)** | `Audit Event Query Failed` | `Database partition query exceeded timeout. Narrow your timestamp range to a 24-hour window to leverage partitioned B-tree indexes.` |

### Destructive Action Confirmation Contract

Destructive operations require explicit operator confirmation dialogues with typed keywords or double-checks:

#### 1. Quarantine Principal ID
- **Modal Title**: `Emergency Principal Quarantine`
- **Confirmation Prompt**: `Type "QUARANTINE" to immediately block all ingress requests for principal ID: [principal_id].`
- **Warning Notice**: `This action writes directly to Redis with a cluster-wide propagation SLA of <5 seconds. All gateway replicas will immediately return HTTP 403 Forbidden (PRINCIPAL_QUARANTINED) for this subject.`
- **Required Input**: `Reason for quarantine (mandatory for audit compliance)`
- **Confirm Button**: `Confirm Quarantine Block` (Disabled until "QUARANTINE" is typed and reason is non-empty)
- **Cancel Button**: `Dismiss Emergency Action`

#### 2. Revoke Token JTI
- **Modal Title**: `Immediate Token JTI Revocation`
- **Confirmation Prompt**: `Type "REVOKE" to invalidate token identifier: [jti].`
- **Warning Notice**: `This action revokes the token cluster-wide across all gateway replicas in Redis. Incoming requests presenting this token will fail immediately with HTTP 401 Unauthorized (TOKEN_REVOKED).`
- **Required Input**: `Revocation justification`
- **Confirm Button**: `Execute Token Revocation` (Disabled until "REVOKE" is typed)
- **Cancel Button**: `Dismiss Emergency Action`

#### 3. Monotonic Policy Rollback
- **Modal Title**: `Monotonic Policy Rollback Confirmation`
- **Confirmation Prompt**: `Confirm rolling back to historical configuration from Snapshot v[target_version]?`
- **Warning Notice**: `To preserve Invariant 9, this action will NOT decrement the version number. Historical policy content will be signed with Ed25519 and published as monotonic version v[latest + 1]. All connected gateway replicas will atomically swap to this snapshot.`
- **Confirm Button**: `Execute Version Rollback`
- **Cancel Button**: `Keep Active Policy`

## Component Inventory & State Machines

### 1. Operator Shell & Layout (`web/dashboard/src/App.tsx`)
- **Visuals**: Full-height application shell with dark slate canvas (`bg-slate-950`), fixed top navigation bar (`h-16 bg-slate-900 border-b border-slate-800`), Aegis shield brand logo, tab navigation pills, and right-aligned operator session badge.
- **Operator Badges**:
  - `sec-ops`: Cyan pill (`bg-cyan-500/10 text-cyan-400 border border-cyan-500/30`) — Full mutation privileges
  - `auditor`: Violet pill (`bg-purple-500/10 text-purple-400 border border-purple-500/30`) — Read-only audit & topology
  - `viewer`: Slate pill (`bg-slate-700/50 text-slate-300 border border-slate-600`) — Read-only routes & drafts
- **Live Session Heartbeat**: Green indicator dot with tooltip showing session expiry countdown (e.g. `Expires in 7h 42m`).
- **CSRF Injection**: Global API client (`web/dashboard/src/api/client.ts`) injects `X-CSRF-Token` header on all mutating calls (`POST`, `PUT`, `DELETE`, `PATCH`).
- **State Machine**:
  - `idle`: Displays authenticated view with selected tab active.
  - `loading`: Top indeterminate progress bar during cross-tab queries.
  - `error`: Banner notification if CSRF or session handshake fails.
  - `success`: Normal operational view.
  - `empty`: If unauthenticated, displays modal overlay: `LoginModal`.

### 2. Policy Studio & Draft Lifecycle (`web/dashboard/src/components/PolicyStudio.tsx`)
- **Visuals**: Split layout.
  - **Left Section (60%)**: Monaco Editor instance with line numbers, custom Rego v1 Monarch syntax highlighting, dark SOC theme, and draft title editor.
  - **Right Section (40%)**: Policy metadata card, in-editor syntax validation results, passed/failed test badges, and version history timeline list.
- **Top Action Bar**:
  - `Validate Rego Syntax` (Secondary CTA, Slate-800 with hover effect)
  - `Publish Policy Snapshot` (Primary CTA, Cyan-600)
- **Monotonic Publish Modal**: Shows current version ($N$), next monotonic version ($N+1$), ETag hash, optional publish comment field, and confirmation CTA.
- **Version History List**: Chronological timeline displaying snapshot version, publisher, publication timestamp, and quick `Rollback` trigger button.
- **State Machine**:
  - `idle`: Editor loaded with active policy draft; publish button enabled if user role is `sec-ops`.
  - `loading`: Spinner on `Validate Rego Syntax` or `Publish Policy Snapshot`.
  - `error`: Inline red alert box showing compilation error line, column, and OPA error string.
  - `success`: Green toast banner: `Snapshot v43 successfully signed and broadcast to fleet`.
  - `empty`: Initial draft template pre-populated (`package aegis.authz ... default allow = false`).

### 3. Dry-Run Policy Simulator (`web/dashboard/src/components/PolicySimulator.tsx`)

- **Primary CTA**: `Execute Dry-Run Simulation` (Cyan-600)
- **State Machine**:
  - `idle`: Request context populated; ready for evaluation.
  - `loading`: Pulse animation on decision inspector card with label `Evaluating in-memory OPA AST...`.
  - `error`: Error alert detailing JSON syntax error or compilation failure.
  - `success`: High-contrast Allow/Deny decision card rendered with evaluation duration.
  - `empty`: Placeholder message: `Simulation Awaiting Request Context. Click Execute to inspect decision.`
